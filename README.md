# Malaria Transmission Dynamics (Ross-MacDonald & SEIR-SEI)

#### Mathematical modelling of *Plasmodium falciparum* transmission and control in Mali, West Africa

This repository provides self-contained, synthetic-compartmental models (no external
downloading of data) of malaria transmission. It implements the classic
**Ross-MacDonald** malaria model alongside a **human SEIR / mosquito SEI** dynamic
vector-borne framework with seasonal (Sahel wet/dry) forcing, and explores the impact
of vector-control and chemoprevention interventions.

---

## Concepts

- **Ross-MacDonald model** — the foundational susceptible/infectious model of malaria
  transmission coupling human and mosquito populations. It formalises how the
  entomological inoculation rate (EIR) drives parasite spread.
- **Vector (mosquito) vs human compartments** — mosquitoes acquire and transmit the
  parasite but never recover (no immune/removal from infection), while humans pass
  through susceptible → exposed → infectious → removed (immune) dynamics.
- **R0 (basic reproduction number)** — the average number of secondary human infections
  generated by a single infected human in a fully susceptible population. For vector-borne
  disease it depends on mosquito biting, survival, latency, and vector:human ratio.
- **EIR (entomological inoculation rate)** — the number of infectious bites per person
  per unit time; a key link between entomology and epidemiology.
- **Vectorial capacity** — the daily rate at which future inoculations arise from a
  currently infective human, capturing mosquito abundance, biting, and survival.
- **ITN/IRS control** — insecticide-treated bed nets (reduce biting / increase mosquito
  mortality) and indoor residual spraying (increase mosquito mortality) both reduce
  transmission and lower the effective reproduction number Rc below the elimination
  threshold.
- **Seasonal transmission** — in the Sahel the intense, short rainy season drives a strong
  seasonal pulse of transmission; dry-season transmission drops dramatically.

## Real-data reference

Mali lies within the high-burden West African Sahel belt, characterised by **intense
seasonal and focal** *P. falciparum* transmission. Transmission peaks during and shortly
after the rainy season (roughly June–October in Bamako), with a near-cessation during the
long dry season. The dominant vectors are members of the *Anopheles gambiae* complex,
which bite readily indoors and at night, making them highly amenable to **ITN** and
**IRS** interventions. Seasonal malaria chemoprevention (SMC) is now a cornerstone of the
national strategy, targeting children under five during the peak transmission months.

## Dependencies

- Python 3.8+
- numpy, scipy, pandas, matplotlib, seaborn, scikit-learn

Install with:

```bash
pip install -r requirements.txt
```

## How to run

From the repository root:

```bash
# 1. Classic Ross-MacDonald equilibrium
python scripts/01_ross_macdonald_sim.py

# 2. Seasonal transmission in the Sahel (3 years)
python scripts/02_seasonal_transmission_mali.py

# 3. ITN / IRS coverage impact and elimination thresholds
python scripts/03_ITN_IRS_impact.py

# 4. Seasonal malaria chemoprevention (SMC) impact
python scripts/04_seasonal_chemoprevention.py
```

Each script prints an interpretative summary to the console and saves 2–3
publication-quality PNG figures into `output/`. All simulations are fully synthetic
(deterministic ODE integration / Monte-Carlo) so they run offline without any downloads.

## Parameterisation rationale

Parameters are realistic for *Anopheles gambiae* in the West African Sahel:

| Parameter | Value range used | Rationale |
|-----------|------------------|-----------|
| Mosquito biting rate `a` | 0.2 – 0.5 bites/day | Nuisance/feeding interval for anophelines |
| Vector:human ratio `m` | 2 – 20 | Typical relative vector abundance |
| Human recovery rate `r` | ~ 1/200 per day | Prolonged untreated infection |
| Mosquito mortality `mu` | ~ 0.1/day | Corresponds to ~10-day adult survival |
| Extrinsic incubation | 8 – 15 days | *P. falciparum* sporogony at ambient temp |
| Host-to-vector infectivity `c` | 0.2 – 0.6 | Infectiousness of gametocyte carriers |
| Vector-to-host infectivity `b` | 0.4 – 0.6 | Sporozoite-positive bite success |

This yields EIR values in the tens-to-hundreds per year in the wet season, consistent
with high-transmission Sahel settings, and R0 values well above 1 that require
substantial control effort for elimination.
